隐私政策 (Privacy Policy)

隐云机场恪守纯净无日志承诺，全方位捍卫您的数字隐私与通信自由

1. 零日志核心承诺 (Zero-Log Guarantee)

隐云机场郑重承诺：我们绝不收集、记录、存储或共享任何用户的网络活动日志。

这意味着在您连接隐云的任何服务器节点期间，我们绝不记录：

  • 您的原始真实来源 IP 地址与物理地理位置；
  • 您所访问的任何目标网站 URL、域名解析查询或 API 请求内容；
  • 您在网络传输过程中的任何数据包有效负载或通信正文；
  • 您每次连接的具体时间戳或断开会话记录。

2. 无盘内存架构运行 (RAM-Only Nodes)

为了从技术架构根源上杜绝数据残留风险，隐云机场的所有专线边缘节点均采用先进的“纯内存无盘操作系统”（RAM-Only System）启动。操作系统与路由程序直接驻留在临时随机存取内存中运行，物理磁盘被彻底禁用写入。每当服务器发生重启或遭遇非正常断电，内存中的所有临时缓存与会话状态均会在微秒内物理彻底消融，任何第三方机构均无法通过硬件提取任何历史痕迹。

3. 我们收集的极少必要运维数据

为了保障您的订阅账户正常计费与提供客户支持，我们仅在控制台核心数据库中保留以下最小化信息：

  • 注册认证邮箱：仅用于账号找回与重要系统维护通知；
  • 累计流量总计数值：仅用于核算套餐配额使用百分比，该数值仅为数字累加量，不含任何流量属性或内容细节；
  • 订阅有效期时间戳：用于管理订阅套餐的到期提醒。

4. 数据加密与第三方共享限制

所有在客户端与隐云中继节点之间传输的数据流均采用业内最高等级的 AEAD 密码学协议（如 ChaCha20-Poly1305 / AES-256-GCM）进行高强度封装，有效防止任何中间人网络监听。隐云机场绝不会将用户的任何账户数据出售、出租或授权给任何广告联盟或商业数据分析机构。
